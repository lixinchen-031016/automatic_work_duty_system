# 自动值班排班系统

基于成员个人课表自动生成值班排班表的桌面应用。上传每位成员的课程表（.xls/.xlsx），系统解析出无课空闲时段，按约束自动生成均衡、无冲突的值班表，并提供甘特图、统计图表与多种格式导出。

- **技术栈**：Python 3.10+ · PySide6（桌面界面） · pandas / openpyxl / xlrd（表格处理） · SQLite（本地存储）
- **纯本地运行**：无需服务器，所有数据保存在本地数据库，关闭程序不丢失
- **界面风格**：类苹果设计语言（macOS 浅色：白色圆角卡片、系统蓝 #007AFF、8pt 间距）

## 功能特性

### 课表管理

- **上传解析**：支持 `.xls` / `.xlsx` 个人课表，自动提取姓名、学号、班级、课程名、教师、地点、周次、节次。
  - 兼容合并单元格、单格多门课程、教师名断行、混合周次（如 `1,3,5` / `1-10`）等常见格式。
- **智能去重**：重复上传同一成员（同「学号+姓名」）自动更新其课表，不会产生重复成员。
- **安全删除**：删除成员需确认，确认框默认聚焦「取消」，防止误删。

### 智能排班

- **硬约束**（绝不允许违反）：
  - 值班时段内无课（时段块的每一节都无课才算空闲）；
  - 避开请假日；
  - 每人每天最多值 1 次（可调）；
  - 每人每周不超过设定上限。
- **软目标**（尽量均衡）：三级贪心均衡——总次数 → 本周次数 → 当天次数，优先安排累计次数最少的成员。
- **动态覆盖均衡**：优先安排当前覆盖最少的星期和时段，保证周一至周五每天都有人值班（避免"周五永远没人"的问题）。
- **按周增量排班**：每次只重排「值班周范围」内的周，范围外的历史排班保留并计入均衡基数——每周只排本周的班，长期下来总量依然均衡，且每周基于最新课表 / 请假情况独立生成。
- **结果持久化**：排班结果存入 SQLite，程序关闭后不丢失，重新打开自动恢复。

### 请假 / 临时占用

- 按成员 + 周次 + 星期登记请假及原因，同一天重复登记自动覆盖。
- 排班自动避让请假日；甘特图中当天整行标红。
- 一键**导出请假记录**（Excel：成员、学号、周次、星期、日期、原因）。

### 手动微调

- 双击值班排班表任一时段单元格，弹出微调对话框，可**换人 / 新增 / 移除**。
- 候选列表实时标注不可用原因（有课 / 请假 / 当天已值班 / 本周已达上限）。
- 周上限为软约束：饱和时可"知情越限"换人；课程冲突、请假、每天一次始终拦截。

### 可视化

- **空闲甘特图**：行=成员，列=星期×时段。颜色含义：
  - 🟩 绿色=空闲　⬜ 灰色=有课　🟦 蓝色=已排值班　🟧 橙色=全员空闲　🟥 红色=请假
  - 底部汇总行显示各时段空闲人数，顶部提示全员空闲时段，支持按周切换、按星期/时段筛选。
  - 可导出带填充色的 Excel 甘特图。
- **统计图表**：三张柱状图——各成员值班总次数、每周值班人次、各成员请假天数，一键导出高清 PNG。

### 导出

| 格式 | 内容 | 说明 |
| --- | --- | --- |
| Excel（多 Sheet） | 值班总表 / 值班明细 / 值班统计 / 无人可用时段 | 表头着色、列宽自适应、含日期列 |
| CSV | 值班明细 | UTF-8 BOM，Excel 可直接打开 |
| PNG 图片 | 值班总表渲染图 | 高清 2x，方便发群通知 / 打印 |
| Excel（请假） | 请假记录 | 从请假登记卡片导出 |
| Excel（甘特图） | 忙闲矩阵 | 带填充色，冻结首列 |
| PNG（统计图） | 三张统计柱状图 | 纵向拼接，高清 2x |

- **导出前可选周数**：导出值班表（Excel/CSV/PNG）时弹窗选择"全部周"或某一周，文件名自动带周次（如 `值班排班表_第5周.xlsx`）。
- **周次自动换算日期**：设置学期起始日（第一周周一）后，排班表自动显示每条值班的具体日期，支持跨月、跨年。

### 易用性细节

- 参数（周范围、星期、时段、上限、种子、起始日等）经 QSettings 持久化，重启自动恢复。
- 修改参数或成员后，旧结果标记"⚠ 可能过期"，提示重新生成。
- 双击成员列表直接跳转「成员课表」页并定位该成员。
- 空数据时有引导提示（如何上传、如何生成）。
- 固定随机种子可复现同一份排班，改种子可换一版均衡方案。

## 安装与运行

### 环境要求

- Python 3.10 及以上（开发环境为 3.13）
- macOS / Windows / Linux 桌面环境

### 安装步骤

```bash
# 1. 进入项目目录
cd automatic_work_duty_system

# 2. 创建并激活虚拟环境
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt
```

依赖清单（`requirements.txt`）：

```
xlrd>=2.0.1      # .xls 解析
openpyxl>=3.1    # .xlsx / Excel 导出
pandas>=2.0      # 表格构建
PySide6>=6.7     # 桌面界面
```

### 启动

```bash
.venv/bin/python app.py          # Windows: .venv\Scripts\python app.py
```

> **注意（TRAE / 部分终端环境）**：若启动报 Qt 或 import 错误，请使用
> `env -u PYTHONHOME -u PYTHONPATH .venv/bin/python app.py`
> 以清除干扰的环境变量。

## 快速上手

1. **上传课表**：左侧「成员」区点击「上传成员课表…」，选择每位成员的 .xls/.xlsx 课表文件（可一次多选）。成员列表出现姓名与课程数即解析成功。
2. **设置参数**：确认值班周范围、值班星期、值班时段、每时段人数、每周/每天上限；填写「学期起始日」（第一周周一的日期，用于周次换算日期）。
3. **登记请假**（可选）：在「成员课表」页选择成员，点击「添加请假…」登记临时不可值班日。
4. **生成排班表**：点击左侧「生成排班表」。摘要区显示人次、缺口、均衡极差等结果。
5. **导出发布**：点击「导出 Excel / CSV / 图片」，选择要导出的周数，即可发布到群里。每周推进时把周范围改成下一周，重新生成即可——历史周不受影响。

### 推荐的按周推进工作流

```
第 1 周开学：周范围 1–18，一次性生成整学期
每周固定动作：
  ① 有新请假 → 请假登记
  ② 周范围改为「本周 至 本周」（如 5 至 5）
  ③ 点击「生成排班表」→ 只重排本周，其他周保留且计入均衡
  ④ 导出本周值班表（选周=本周）发群
```

## 排班规则详解

### 硬约束（算法保证，手动微调也不可越过）

1. **无课冲突**：值班时段块内的每一节都不能有课（如值 1-2节 需第 1、2 节都无课）。
2. **请假日不可值班**：登记请假的成员当天任何时段不参与排班。
3. **每天一次**：每人每天最多值 1 次班（参数可调，默认 1）。
4. **每周上限**：每人每周不超过设定次数（默认 3）。

### 软目标（贪心均衡）

- 安排顺序按三级优先级挑选成员：**累计总次数最少 → 本周次数最少 → 当天次数最少**。
- 任务处理顺序采用**动态覆盖均衡**：优先安排当前覆盖最少的（星期 × 时段）组合，确保每天都排满、避免某天整天空缺。
- 平手时按随机种子决定，保证同参数可复现。

### 按周增量排班

- 生成时只**重排**「值班周范围」内的周；范围外已有排班：
  - 原样保留在结果和数据库中；
  - 计入总次数均衡基数（历史值多的成员本周少排）。
- 由此实现"每周生成每周对应的值班表，且和以前互不影响"。

### 手动微调

- 双击值班表单元格 → 对话框显示当前值班人、可换/可增候选。
- 候选标注原因：可换（空）/ 该时段有课 / 请假 / 当天已值班 / 本周已达上限。
- 「本周已达上限」为知情越限项（软约束），选中后界面提示风险；其余为硬约束不可选。
- 应用后立即重写数据库并刷新统计。

## 数据存储

单一 SQLite 文件 `duty_system.db`（项目根目录，自动创建）：

| 表 | 字段 | 说明 |
| --- | --- | --- |
| `members` | id, student_id, name, class_name, term, file_name, course_count | 成员（student_id+name 唯一，重复上传更新） |
| `courses` | id, member_id, course_name, teacher, location, weeks, weekday, sessions | 成员课表课程记录 |
| `duty_assignments` | id, week, weekday, block, member_id, member_name；UNIQUE(week, weekday, block, member_id) | 值班安排 |
| `leaves` | id, member_id, week, weekday, reason；UNIQUE(member_id, week, weekday) | 请假记录 |

- 删除成员时其课程、值班、请假记录级联删除。
- 界面参数（不含排班结果）另存于 QSettings。
- 备份：直接复制 `duty_system.db` 文件即可完整备份全部数据。

## 项目结构

```
automatic_work_duty_system/
├── app.py                    # 主应用：PySide6 界面（六页签 + 参数面板 + 导出/微调/图表）
├── test_system.py            # 端到端测试（13 组场景）
├── requirements.txt          # 依赖清单
├── duty_system.db            # SQLite 数据库（运行时自动创建）
├── samples/                  # 示例课表（.xls）
└── duty_system/              # 核心包
    ├── parser.py             # 课表解析：.xls/.xlsx → 课程记录（周次/节次/姓名/学号）
    ├── database.py            # 数据层：members / courses / duty_assignments / leaves
    ├── scheduler.py          # 排班算法：约束过滤 + 三级均衡 + 动态覆盖 + 微调候选
    ├── exporter.py           # 导出：明细/透视/统计 DataFrame → Excel/CSV、周次换算日期
    └── gantt.py              # 空闲甘特图：忙闲矩阵构建 + 带填充色 Excel 导出
```

### 核心调用关系

```
上传课表 → parser.parse_schedule_file() → database.upsert_member()
生成排班 → scheduler.generate_schedule(members, courses, config, leaves, base)
         → database.save_assignments()（增量：先 delete_assignments_for_weeks）
展示     → exporter.build_pivot_df / build_detail_df / build_stats_df
甘特图   → gantt.build_availability(members, courses, week, leaves, assignments)
导出     → exporter.export_excel / export_csv；app.render_table_png / render_charts_png
```

## 常见问题

**Q：为什么周五（或某天）排不出值班？**
早期版本按周一→周五固定顺序排班，前几天耗尽每周额度导致周五无人。现已改为动态覆盖均衡，优先安排覆盖最少的星期。若仍出现缺口，请查看「值班统计」页的「无人可用时段」清单——表示该时段全员有课或请假，属客观不可排。

**Q：生成的排班表会覆盖以前的吗？**
不会。只重排「值班周范围」内的周；范围外的历史排班保留并计入均衡基数。想整学期重排，把周范围设为整个学期再生成即可。

**Q：关掉程序后排班结果还在吗？**
在。结果实时写入 `duty_system.db`，重新打开程序自动恢复，无需重新生成。

**Q：修改了参数/成员后旧结果还能用吗？**
能看，但摘要区会提示"⚠ 排班参数或成员已变化，结果可能过期"，建议重新生成。

**Q：导出的 Excel 周次能换成具体日期吗？**
能。左侧设置「学期起始日」（第一周周一）后，明细表、透视表、Excel、CSV、PNG 均自动附带日期列，支持跨月/跨年。

**Q：双击值班表单元格没反应？**
请双击右侧「值班排班表」页的表格内容单元格（表头的周次/星期/日期列除外），会弹出手动微调对话框。

**Q：随机种子是干什么的？**
平手时决定分给谁。固定种子 = 同样参数生成完全相同的排班（可复现）；换一个种子 = 换一版同样均衡的方案。

**Q：如何在终端/TRAE 环境运行脚本？**
若遇 Python 环境变量冲突（Qt 报错或 import 异常），使用：
`env -u PYTHONHOME -u PYTHONPATH .venv/bin/python app.py`
